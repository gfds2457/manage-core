# 商品后台管理系统需求

## 浅层需求（基础可见功能）

1. 用户登录
   - 账号密码登录
   - 获取登录用户信息
2. 商品分类管理
   - 一级/二级/三级分类：新增、编辑、删除
3. 属性管理
   - 属性名称维护、属性值维护
4. SPU管理（产品机型管理）
   - SPU新增、编辑、删除
   - 获取SPU列表、SPU详情
5. SKU管理（单品库存价格）
   - SKU新增、编辑、删除
   - 获取SKU列表，维护价格、库存

## 深层需求（上线后的业务、异常、运营、风控）

### 商品管理（异常场景）

1. 商品软删除与恢复：删除商品不是直接销毁，支持恢复误删商品
2. 商品草稿版本：编辑SPU可保存草稿，支持版本回退
3. 批量操作：批量上架/下架、批量修改分类、批量修改属性
4. 商品状态：商品上架、下架、待审核状态，违规商品强制下线
5. 数据校验：价格、库存不能填写负数，非法输入拦截

### 商品统计（业务数据分析）

1. 商品总数统计：上架/下架商品数量
2. 商品访问统计：SPU浏览、点击数据
3. 分类统计：各分类商品数量分布
4. 报表导出：商品列表、统计数据导出Excel

### 权限管理（多人协作）

1. 角色权限：管理员、商品录入员、审核员、只读查看员
2. 细粒度权限控制：区分查看、新增、编辑、删除权限
3. 操作日志：记录谁、什么时间，修改了哪一条商品，操作留痕

### 后台运维管控

1. 商品内容风控，违规描述拦截
2. 分类启用/禁用，禁用分类不可新建商品
3. 属性启用/禁用，禁用属性不能绑定商品
